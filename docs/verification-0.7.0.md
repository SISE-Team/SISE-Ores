# SISE Ores 0.7.0+26.1.2 / SISE Compat 0.4.0+26.1.2 生产统一验证

2026-10-16，在实际安装的 222 个模组环境中完成独立客户端、新建世界、原生机器、JEI 和资源重载检查，随后安装同一对已测试产物。升级前基线为 Ores 0.6.0 / Compat 0.3.0；未改写上游模组 JAR、Minecraft 或公共库。

## 生产规则

优先级为 Mekanism（含 Generators）→ MekMM → Modern Industrialization → Oritech → EnderIO → LTXI → NeoEcoAE → Ice and Fire → CakestickLib → 其他模组 → IC2CE。普通物品、流体外观和生产参考使用同一顺序，IC2 始终最后。原版铁／金／铜等已有原版统一目标继续保留。

按相同原料比例、相同生产阶段与相同主产物比较每单位投入的产出数量、概率与副产物；不同纯度、压块／拆分、离心／洗矿等阶段保持各自单位关系。没有同类参考的路线保留自身产量，升级和原生机器机制继续有效。

共审阅 1497 条相关资源配方；其中 1380 条实际加载配方、806 个输入／工艺分组经过实际解码对照。未加载的条件配方与动态采气、带组件升级成品在 production-audit.json 中明确记录。83 条完整来源保护规则全部应用，用户数据包或上游更改来源后会跳过并记入日志。

- 粗铜、粗铁、粗金、粗锡、粗铅、粗锇、粗铀、粗银等重复磨粉路线采用参考比例；需要时扩大为整数批次，例如 3 粗铜 → 4 铜粉。MI 使用原生数量原料，SAG 和 Oritech 使用可同步的批次原料并补齐实际扣料。
- SAG／Oritech 不足一批不能匹配，仍可逐个送入原料；实测 SAG 扣 3 留 3，Oritech 不足批次不扣料、事务回滚恢复 6、提交后扣 3 留 3。CSL 手动路线使用三个实际原料格及相应锤损耗。扩大批次同步扩大用料与时长／总能耗。
- 普通板材、青铜粉、部分硅和琥珀金、矿石转粗矿、黑曜石粉、盐酸与水电解等重复生产按参考产物与比例对齐；保持原配方 ID 和原生加工方式。制造冲突继续使用合理布局或可返还工具，没有改成切石机。

## 蒸汽、液体和化学品

保留 178 个物品组、176 个 SISE 物品形态和 443 个旧物品 ID，其中 IC2CE 64 个。流体 18 组覆盖 72 个旧静止／流动 ID 和 46 个旧桶。化学品为 UU、蒸汽、氢、氧、氯、硫酸六组，在对应注册表使用 SISE 身份。

截图中的热力锅炉蒸汽属于 Mekanism 化学品注册表。本轮补齐该真实产出入口：实际锅炉水箱减少量等于蒸汽箱增加量，蒸汽箱内容为 `sise_ores:steam`；JEI 自动生成的两条热力锅炉配方也显示 1 mB SISE 蒸汽。六组化学品的燃料／冷却／辐射属性均与来源相同。

普通蒸汽以优先模组的 1 mB 水 → 1 mB 蒸汽计量。MI 锅炉与 15 条普通蒸汽生产／消耗配方同步对齐，保留其他原料的批次比例；IC2 压力锅炉普通／过热蒸汽及冷凝计量保持一致，100 mB 蒸汽实测回收 100 mB 水。IC2 汽轮机冷凝记账采用同一水当量，其原生冷凝比例与排汽行为保留。Oritech 锅炉附加组件的原实现已经是等量水／蒸汽，无需数量补丁。锅炉供热和发电继续使用各模组原生算法，本轮不统一不同模组的能量体系。

流体与化学品仍使用各自原生管道／储罐，未新增物态转换。低温液氢／液氧／液氯、同位素、过热／高压蒸汽保持独立身份。JEI 浏览与配方轮换隐藏已审核旧身份，只显示对应 SISE 材料；创造标签页和搜索隐藏旧物品／桶。
